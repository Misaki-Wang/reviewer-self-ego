# Presentation and collaboration artifacts

- main_experiment.html: the experiment-design page imported from GitHub.
- ACL2026-t1.1-vs-t1.2.html: the existing self-contained calibration comparison
  page, including its embedded statistics and previews; bytes preserved.

Place future result visualizations and discussion/sync HTML here. Raw results,
responses and execution receipts belong in ../res. Current source JSON and PDFs
belong in ../data/index and ../data/pdf.

- [review-exp-iclr2026-pilot.html](review-exp-iclr2026-pilot.html): standalone ICLR 2026 review pilot summary, with scope, original conditions/prompts, descriptive findings, timing/token accounting and full review previews. Download and open in a browser; source data is published under [../res/published/review_exp_iclr2026_pilot/](../res/published/review_exp_iclr2026_pilot/).

- [ICLR2026-check-diff-summary.html](ICLR2026-check-diff-summary.html): complete
  ICLR2026 run summary with timing, reported usage, descriptive labels, all 1,588
  embedded pair previews and the exact frozen prompt. Download and open locally;
  no network fetch is required for the embedded preview.

- [review-exp-multisource-pilot-20260914.html](review-exp-multisource-pilot-20260914.html): completed ten-source review pilot (100 papers, 364 versions, 4,368 reviews), with source-specific score scales, full review comparisons, exact prompts and audited time/token statistics. The report works offline; separate raw-file links use the [published package](../res/published/review_exp_multisource_pilot_20260914/).

- [remaining-sources-check-diff-summary-20260914.html](remaining-sources-check-diff-summary-20260914.html): completed nine-source comparison run, with all 6,814 pair previews, source-conditioned labels, exact prompts, unavailable inputs, and audited time/token accounting. Download and open locally; original-record links use authenticated GitHub file views. [Selected data](../res/published/check_diff_remaining_sources_20260914/README.md).

- [review-exp-multisource-3model-latest-pilot-20260914.html](review-exp-multisource-3model-latest-pilot-20260914.html): completed three-model pilot across ten sources, five papers per source and one latest indexed original version per paper; 4,350 reviews under 29 canonical conditions. Includes source-specific distributions, paired comparisons, full review previews, exact prompts, and audited time/token statistics. [Selected results](../res/published/review_exp_multisource_3model_latest_pilot_20260914/README.md).
