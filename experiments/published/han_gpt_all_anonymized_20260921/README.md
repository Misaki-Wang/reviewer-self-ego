# Frozen GPT review study

This versioned study contains 28,106 accepted judgments for 3,124 anonymized PDF versions across five conferences. It covers GPT-5.5, GPT-5.6-Sol, and GPT-6-Astra, each at medium reasoning effort, under exp1_quality, exp3_positive, and exp3_negative.

The study joins 19,045 audited owned judgments with 9,061 exact, hash-bound historical accepted judgments. Ten held cells are listed in MANIFEST.json and have no accepted value in this study. Historical values for some held identities may remain in the separate canonical collection; they are not counted here.

The current collection under data_5conf/review is preserved separately. Its historical studies can have different results for the same paper/version/model/condition address. Use this directory and its manifest for the frozen study. Source-specific scores and complete judgments are retained.

MANIFEST.json records the source mapping, accepted counts, held identities, evidence hashes, and each review file's SHA256. Publication reused completed execution evidence and exact final review values; it launched no model calls and reread no PDFs or raw model protocols.
