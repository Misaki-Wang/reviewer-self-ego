captured on 2026-09-18 at 17:56 UTC. The 1,145 source files were copied byte for
byte and verified with SHA-256. They include the five-conference metadata,
historical reviews, anonymization receipts, and provenance records.

the source server. Paths, availability fields, and checksums inside the source
metadata describe that server snapshot; they do not imply that the corresponding
PDFs are included in this GitHub checkout. Historical records retain their
original scope and timestamps. The source directory was not modified.
