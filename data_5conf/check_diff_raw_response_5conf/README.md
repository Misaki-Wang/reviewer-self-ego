# Five-conference check_diff raw responses

This directory contains 9,066 JSON response files copied byte-for-byte from the MBZ project path `raw_response/check_diff_raw_response_5conf/` on 2026-09-24. The filenames retain the form `<arxiv_id>__v<earlier>_v<later>.json`. No PDFs are included.

Per-source file counts: ACL 2026: 1,004; CVPR 2026: 1,143; ECCV 2026: 775; ICLR 2026: 3,252; ICML 2026: 2,892.

`SHA256SUMS` records the SHA-256 digest of each response JSON. `../stastics.md` records the source/index and arXiv-confirmation counts shown in the accompanying statistics screenshots.
